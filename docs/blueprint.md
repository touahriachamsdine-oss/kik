# **App Name**: رحلتي Trip Planner

## Core Features:

- User Authentication: Secure user registration and login via email, Google, or Facebook.
- Agency Registration and Management: Allow agencies to register (with verification), create, and manage travel packages.
- AI-Powered Trip Recommendations: AI tool that analyzes user preferences to offer personalized destinations, tailored experiences, and curated suggestions based on available travel packages. Includes budget considerations.
- Intelligent Search & Filtering: Enable users to find and filter travel packages by destination, date, budget, trip type (family, adventure, etc.), and ratings.
- Secure Booking & Payments: Provide a seamless booking experience with multiple payment options (credit cards, local methods like CIB/BaridiMob, and cash on delivery). Generate PDF invoices and manage booking confirmations.
- Review and Rating System: Enable users to rate and review their trips and agencies. Display average agency ratings based on reviews.
- Wishlist Feature: Users can save preferred destinations/packages to a wishlist.

## Style Guidelines:

- Primary color: Deep teal (#008080) to evoke trust and stability.
- Background color: Light teal (#E0F8F7), a very lightly saturated version of the primary, for a calm and professional feel.
- Accent color: Muted yellow (#B7950B), to suggest warm energy in an understated way; call attention to actionable elements and important info.
- Headline font: 'Playfair', a modern serif, paired with body text 'PT Sans', a humanist sans-serif.
- Modern and clean icons that are intuitive and easy to understand.
- Clean and organized layout with a focus on usability and responsiveness across all devices.
- Subtle micro-interactions to enhance the user experience without being distracting.
